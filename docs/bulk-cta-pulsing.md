Разные проценты масштабирования по X/Y вычисляются из размеров каждой кнопки. Масштабирование самой кнопки 1 → 1,02 → 1 и цикл 1,8 с сохранены; пульсируют пять кнопок. Управления анимацией нет. Пульсируют три Get a Bulk Quote на главной (hero, Fast, In-House Engraving, Ready to start your project?) и две на Bulk Orders (Fast, In-House Engraving и What do you have in mind?). ## Изменённые файлы этого запроса

- `assets/revision.css`: inset −2 px учитывает существующую 2-пиксельную границу .btn, поэтому кольцо начинается на внешнем крае кнопки на всех экранах. Scale по горизонтали/вертикали разный, но прибавка расстояния от края одинаковая: 0 → 3 → 4 px. Анимируются только transform и opacity псевдоэлемента; кольцо 2 px, свечение 6 px, максимальная opacity 0,65. Оба цикла — 1.8s / ease-in-out / infinite, с общим `--ev-bulk-play-state`. На стыке циклов кольцо прозрачно; reduced motion отключает оба эффекта. Размеры кнопки и отступы в потоке прежние.
- `assets/revision.js`: для каждого выбранного CTA задаются коэффициенты `--ev-bulk-halo-x/y` по размерам border box. Общий ResizeObserver пересчитывает их после изменения размеров, включая адаптивный экран/шрифты; transform самой кнопки не вызывает пересчёт. Без ResizeObserver используется начальный замер и обновление при resize/готовности шрифтов. При section unload снимаются наблюдение и обе переменные, при последнем unload observer отключается.

Существующие Map/IntersectionObserver продолжают наблюдать выбранные кнопки; оба эффекта используют прежнее состояние видимости/вкладки/reduced motion. Защита от повторного mount сохранена. Targeting, включая финальный CTA Bulk Orders в `sections/b2b-content.liquid`, не менялся.

Управления, сообщения или замены управления нет. Отступы восстановлены удалением разметки и CSS прежних контролов. JavaScript не вставляет элементы и не сдвигает контент. Нет popup, sticky bar, нового раздела, библиотеки или дополнительных image/script requests.

Prefers-reduced-motion автоматически выключает декоративное движение, без текста/сообщений. Без JavaScript/IntersectionObserver нет пульса, ссылки и подписи доступны. Прежняя ручная пауза была только переменной в памяти, не записывалась в cookies/localStorage/sessionStorage; переменная удалена. Чужие предпочтения и cookies не очищались.

Аудит хешей этого запроса: изменены только CSS и JavaScript выше; 94 остальных файла побайтово прежние, включая все Liquid-секции, JSON-шаблоны, настройки, header/footer, формы, фото, видео и шрифты. Ссылки, подписи CTA и quantity statements не менялись.

## Проверки

Обновлён `scripts/verify-release.cjs`. Chrome, desktop 1440×900 и mobile 390×900 с isMobile/hasTouch для проверки пульса.

- Каждая из пяти настоящих CTA на обоих размерах проверена 10,1 с: минимум пять animationiteration. Через requestAnimationFrame измерены масштаб кнопки, opacity и расстояние расширения кольца по каждой оси: пик 3 px, полный диапазон до 4 px; максимальная измеренная разница между осями менее 0,001 px. Сохранены реальные кадры спокойной фазы, пика и затухания. Пересчёт коэффициентов после изменения ширины viewport и возвращения прошёл.
- После прокрутки за пределы экрана play-state становится paused; за 1,9 с счётчик не меняется. После возвращения running и счётчик продолжает расти.
- Во всех 21 JSON-шаблонах и в настоящих header/footer нет управления. Только пять кнопок имеют маркер пульса; текст и href проверяются. Границы экрана/overflow-предки проверяются с учётом обоих transform и хвоста свечения. Клик в центре каждой кнопки получает событие; переход перехвачен тестом, заявки не отправляются.
- Скрытая вкладка: проверен обработчик document.hidden/visibilitychange с имитацией состояния в браузере; цикл останавливается и возобновляется. Это не проверка физического переключения вкладок на телефоне.
- Reduced motion автоматически выключает движение и разрешает его после возврата, без управления и сообщений.
- Повторные section:load не дублируют наблюдение; unload/remount сохраняют управление, финальный unload снимает класс/стили/наблюдение. Удалён обработчик остановки после animationend.
- Размеры и позиции CTA в потоке (offsetWidth/Height/Left/Top) сравниваются до/после циклов и прокрутки; отдельно измеряются layout-shift entries. Визуальная рамка закономерно меняется из-за transform. Клавиатурный фокус, desktop arrow 3 px, кнопки покупки и шапки проверяются. Новых сетевых запросов при циклах/перезагрузке нет.
- Проверены reduced motion, отсутствие JavaScript и IntersectionObserver, доступность ссылок и минимальная высота CTA; отдельная проверка resize-fallback без ResizeObserver.
- Повторно проверены Liquid-рендер 21 JSON-шаблона, первый экран шести страниц на обоих размерах, отсутствие горизонтального переполнения и регрессий видео. Все 11 групп прошли, ошибок JavaScript нет.
