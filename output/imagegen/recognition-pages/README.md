# Разные подарки для страниц 15–21

31 отдельное изображение, формат 4:3. Общий светлый тёпло-серый фон и мягкий свет. Разные товары, гравировки и композиции; один финальный файл назначен одному блоку.

Это AI-концепты по локальным фотографиям ассортимента, не фото готовых клиентских заказов. Комплектацию и доступность подтвердите перед публикацией. Прозрачные награды намеренно названы clear award в alt: точный материал по фото не подтверждён.

[Открыть визуальную галерею](gallery.html) · [Alt-тексты CSV](alt-texts.csv) · [Промпты и референсы](prompts.json) · [Скачать ZIP](recognition-pages-elma-vada-dfw.zip)

Генератор: встроенный imagegen, без API/CLI. PNG сохранены без изменения расширения. Отдельного AEO-alt нет: английские описания называют видимые предметы, материал и гравировку. Все alt короче 125 символов.

## Как использовать

1. Найдите страницу и блок ниже.
2. Загрузите указанный файл в Shopify Files.
3. Выберите его в Photo, Media type → Image; включите Include image or video, если поле есть.
4. Скопируйте alt в Photo description. Проверьте мобильное кадрирование.
5. Добавьте видимую подпись Illustrative gift concept. Для цифровых макетов — Illustrative mockup — your final proof is prepared for your project.

В страницах 15–19 повторяющиеся процессные и навигационные карточки оставлены текстовыми. В страницах 20–21 Hero и боковое фото формы необязательны. Фото людей не синтезировались. Shopify и код темы не менялись.
