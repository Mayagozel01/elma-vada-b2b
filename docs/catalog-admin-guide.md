# Каталог Elma Vada — инструкция для Shopify Admin

Актуальная доработка статусов наличия, точного количества и цен: [catalog-inventory-guide.md](catalog-inventory-guide.md). Меню `Catalog categories` уже создано и подключено; повторно создавать его не нужно.

## Однократная настройка

1. Загрузите новую тему как **неопубликованную**, откройте её Preview / Edit theme. Не нажимайте Publish во время проверки.
2. **Theme settings → Product catalog → Catalog categories menu**: выберите меню `Catalog categories`. Настройка общая для каталога, стандартных коллекций и шаблона `catalog`.
3. **Collections → Default collection → Product catalog**: задайте **Main catalog heading** (`Product Catalog`) и **Catalog introduction**. На странице `/collections/all` показываются эти тексты; внутри категории — название коллекции. Опция **Use collection description on category pages** позволяет использовать описание категории или общий вводный текст.
4. Оставьте **Category menu override** пустым: тогда все коллекции используют общее меню. Если раньше в секции выбрали другое меню, очистите override либо выберите тот же `Catalog categories`. Проверьте также альтернативный шаблон **Collections → catalog**.
5. Коллекции категорий должны использовать **Default collection** или **catalog**, а не сторонний шаблон без секции каталога. Категории и товары должны быть доступны в канале **Online Store**.
6. Определение короткого названия: **Settings → Metafields and metaobjects / Custom data → Products**. Сначала найдите `custom.catalog_title`; если оно уже существует с типом **Single line text**, используйте его. Иначе **Add definition**: название `Catalog title`, namespace/key `custom.catalog_title`, тип **Single line text**. Закрепите поле для удобства. Другие типы поля требуют согласования, не удаляйте существующее определение наугад.

Код не создаёт коллекции, меню или metafield definitions в админке. Все перечисленные настройки нужно сохранить в магазине.

## 1. Создать категорию

В витрине используются существующие коллекции: **Engraved Chopsticks** (`/collections/custom-engraved-chopsticks`), **Engraved Desk Accesories** (`/collections/engraved-desk-accesories`), **Engraved Pens** (`/collections/custom-engraved-pens`). Меню `Catalog categories` теперь создано и подключено. Исправление отображаемого названия Desk Accessories в двух реальных источниках описано в [catalog-inventory-guide.md](catalog-inventory-guide.md); URL менять не требуется.

В **Products → Collections** сначала проверьте существующие согласованные коллекции. Если подходящая уже есть — используйте её. Для новой: **Add / Create collection**, название, описание, доступность **Online Store**, шаблон **Default collection**. Пустая опубликованная категория допустима: каталог покажет понятное пустое состояние. Не создавайте служебные подборки для меню витрины.

## 2. Автоматически добавлять товары

Shopify постепенно заменяет старую модель Manual / Smart новым интерфейсом Sources. Версия именно вашего магазина не определяется из Liquid темы; проверьте экран коллекции:

- **Новый интерфейс:** в источнике **Products** выберите **Add condition**; используйте согласованный Product tag или Product type и условие совпадения. Укажите **Match all / Match any**, сохраните.
- **Старый интерфейс:** при создании коллекции выберите **Smart / Automated**, добавьте условие **Product tag / Product type → is equal to → согласованное значение**, выберите all / any и сохраните. Не переключайте тип уже существующей коллекции наугад.

Затем заполняйте соответствующий тег или тип в **Products → нужный товар**. Назначайте значения только по согласованной схеме. Товар должен быть **Active** и опубликован в **Online Store**. Если нужны все варианты товара, используйте источник Products, не Variants.

Описание [нового интерфейса коллекций](https://help.shopify.com/en/manual/products/collections/create-collection) и [старых Smart collections](https://help.shopify.com/en/manual/products/collections/smart-collections/create).

## 3. Добавить категорию в каталог

**Content → Menus → Catalog categories → Add menu item**. Введите отображаемое название; в выборе ссылки выберите **Collections → нужная коллекция**. Сохраните меню.

Используйте именно ресурс коллекции, не вручную набранный URL, страницу или ссылку с параметрами фильтров. Тема выводит только доступные ссылки типа `collection_link` с действительным объектом коллекции. Удалённые, неопубликованные или неподходящие ссылки пропускаются. Пункт **All products** добавляется темой автоматически; второй такой пункт в меню не нужен. Используйте один уровень меню, без вложенных категорий.

Новая категория появляется после сохранения и обновления страницы. Название пункта меню может отличаться от названия самой коллекции. На странице категории выделяется её пункт; выбор другой категории сбрасывает фильтры и номер страницы.

## 4. Изменить порядок и название категорий

В **Content → Menus → Catalog categories** перетащите пункты в нужном порядке. Измените название пункта и сохраните. Код темы менять не требуется. При удалении пункта из меню коллекция и товары остаются в магазине.

## 5. Задать короткое название товара

**Products → товар → Metafields → Catalog title**: заполните, например, `Parker Jotter Pen Set` и сохраните. Поле используется в карточках каталога, похожих товаров и подборки на главной. Пустое поле возвращает полное название товара.

Основное название, SEO title, URL и заголовок страницы товара не изменяются. Автоматического обрезания по тире/запятой нет. Ранее короткая подпись над названием бралась из **Product type**; эта подпись больше не выводится в карточках. Не изменяйте Product type только ради заголовка: это может повлиять на правила коллекций. При необходимости вручную перенесите утверждённую короткую подпись в `Catalog title`.

## 6. Включить согласованные цены

До включения подтвердите реальные цены каждого варианта, валюту / Markets и включённую персонализацию. **Products → товар → Variants → Price**: проверьте и сохраните утверждённые значения.

В редакторе проверяемой темы: **Theme settings → Product catalog → Show agreed product prices on cards**. По умолчанию выключено — сохранено предыдущее решение скрывать цены. Включите после согласования и сохраните. Настройка действует сразу на каталог, похожие товары и подборку на главной.

Разные цены вариантов → **From** + минимальная цена Shopify; единая цена → обычная цена. Используется существующий фильтр `money`. Отсутствующая цена не выводит пустой блок; реальная нулевая цена отображается, а не заменяется выдуманной. Эти цены не объявляются оптовыми: корпоративная сумма уточняется через **Request a Bulk Quote**.

Скрытие цен карточек не скрывает данные Shopify, цены страницы товара, корзины или фильтра Price. Это оформление витрины, не средство ограничения доступа к ценам.

## Фильтры и проверка

Проверяемая неопубликованная тема: **Elma Vada Inventory Review 2026-10-15**, ID `160476889274`. [Каталог Preview](https://elmavada.myshopify.com/collections/all?preview_theme_id=160476889274), [редактор этой темы](https://elmavada.myshopify.com/admin/themes/160476889274/editor). Актуальный архив для загрузки: `output/elma-vada-inventory-review-2026-10-15.zip`. Действующая тема не публиковалась и не изменялась этой работой.

Существующие Availability / Price работают через штатные фильтры Shopify. Если фильтры не видны, проверьте **Search & Discovery → Filters**, данные товаров и секцию **Show filters**. Платные приложения не нужны.

В Preview проверьте `/collections/all`, каждую согласованную категорию, сортировку, Availability, диапазон Price, сброс фильтров, пагинацию, ссылки на товары и Request a Bulk Quote. Перейдите в другую категорию после применения фильтра: URL не должен переносить `page` и `filter.*`.

Проверьте цены с включённой настройкой и без неё. Проверьте телефон, клавиатуру Tab / Enter, длинное название категории, товар без фотографии и выдачу без результатов. Фильтры и пагинация обрабатывают всю коллекцию на стороне Shopify, а не только видимые карточки.

## Что остаётся для команды

- Выбрать реальные согласованные коллекции, схему тегов/типов и подтвердить доступный интерфейс коллекций.
- Меню `Catalog categories` уже подключено; проверьте его сохранение в новой теме и исправьте название Desk Accessories в меню и коллекции по инструкции наличия.
- Проверить существующее определение `custom.catalog_title`, создать при необходимости и заполнить короткие названия.
- Согласовать цены всех вариантов и только затем включить их вывод.
- Проверить полноту ассортимента и реальные фотографии, включая коробочки; тема не добавляет товары и не дорисовывает отсутствующие фото.
- Проверить получателя заявок и отправить реальную тестовую заявку самостоятельно. Локальные тесты не отправляют заявки и не создают заказы.

После этой первоначальной настройки категории, их порядок, короткие названия, цены и товары изменяются в Shopify Admin без новой правки кода темы.
