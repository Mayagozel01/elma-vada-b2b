# Каталог, товар и корзина — вариант 3

Архив для загрузки в Shopify: `output/elma-vada-ready-2026-10-15.zip`. В корне ZIP находятся папки темы, без внешней папки проекта; скриншоты, тесты и документация в пакет не включены.

Актуальная настройка компактного корпоративного каталога описана в [catalog-admin-guide.md](catalog-admin-guide.md). В карточках поддерживаются `custom.catalog_title` и настройка **Theme settings → Product catalog → Show agreed product prices on cards** (по умолчанию выключена); цены страницы товара и корзины сохранены. Категории задаются общим меню **Catalog categories menu**, секция может переопределить его. Исправление недопустимых defaults URL в схеме каталога сохранено.

## Локальный просмотр

Установленный Shopify CLI требует Node.js 22.12 или новее. В проекте версия закреплена файлом `.nvmrc`: 22.23.3, уже установленная через nvm.

В терминале из корня темы выполните:

```bash
nvm use
shopify theme dev --store elmavada.myshopify.com --ignore hero.liquid
```

Если терминал не знает команду `nvm`, сначала выполните `source /home/yus/.nvm/nvm.sh`.

После входа в Shopify откройте `http://127.0.0.1:9292/collections/all`. Оставьте команду работающей; изменения будут подхватываться при сохранении. Остановка — Ctrl+C. Просмотр использует данные магазина и требует подключения к Shopify; команда создаёт или обновляет development theme.

[Требования Shopify CLI](https://shopify.dev/docs/api/shopify-cli).

## Подключение после загрузки ZIP

1. **Online Store → Themes → Add theme → Upload zip file**. Откройте Preview загруженной темы.
2. Каталог `/collections/all` теперь использует новый **Default collection** автоматически: заменён стандартный шаблон коллекции. Создавать страницу в Pages или назначать системной коллекции отдельный шаблон не нужно.
3. Обычные товары с шаблоном **Default product** используют новый шаблон автоматически. Если товар уже имеет другое назначение, откройте **Products → нужный товар → Theme template**, выберите **Default product** и сохраните. Назначения ресурсов находятся в админке, а выбор товара в редакторе темы служит для предпросмотра.
4. Для оформления каталога: **Edit theme / Customize → Collections → Default collection → Product catalog**. Измените вступление, количество товаров на странице, категории и блок корпоративной заявки. Для коллекций с назначенным `catalog` выберите **Collections → catalog**: это отдельные настройки.
5. Для страницы товара: **Products → Default product → Product details** в верхнем селекторе редактора темы. Здесь меняются подписи кнопок, оптовый блок и порядок раскрывающихся блоков. Секция **Related products** управляет похожими товарами.
6. Корзина открывается по ссылке **View cart**, добавление товара ведёт в неё. Кнопка **Checkout** переводит к оформлению Shopify. Приём оплаты, доставка и налоги зависят от настроек магазина.

Подробнее о [назначении шаблонов в Shopify](https://help.shopify.com/en/manual/online-store/themes/theme-structure/templates).

## Шестой пункт главного меню

**Content → Menus → ваше главное меню**: шестым пунктом добавьте `Catalog`, ссылка **All products** (`/collections/all`).

В редакторе темы **Header → Main menu** выберите это меню. Если меню не выбрано, шестой пункт уже присутствует в запасном меню темы.

## Категории каталога

1. В **Products → Collections** создайте реальные категории вашего ассортимента: например Pens, Drinkware, Gift Sets, Awards — только если такие товары есть.
2. Добавьте товары в соответствующие коллекции вручную либо настройте автоматические правила по Product type/тегам.
3. В **Content → Menus** создайте меню `Catalog categories`; выберите ссылки через **Collections → нужная коллекция**, одним уровнем меню.
4. В **Theme settings → Product catalog → Catalog categories menu** выберите это меню и сохраните.
5. В используемых шаблонах **Default collection** и **catalog** оставьте **Category menu override** пустым, чтобы они использовали общее меню. Для автоматического наполнения следуйте инструкции для версии коллекций в [catalog-admin-guide.md](catalog-admin-guide.md).

Без выбранного меню остаётся ссылка All products, каталог продолжает работать. Недоступные/удалённые коллекции и ссылки других типов не выводятся. Все коллекции со стандартным шаблоном используют новую сетку.

## Фильтры и сортировка

Сортировка работает по стандартным вариантам коллекции. Фильтры выводятся из настроенных данных Shopify.

В **Apps → Shopify Search & Discovery → Filters** включите нужные фильтры: Availability, Price, Product type, Color и Material. Для Material используйте определение `custom.material`. Заполните типы, цвета и материалы у самих товаров. В теме включите **Product catalog → Show filters**. Кнопка **Apply filters** применяет выбранные параметры ко всей коллекции, а не только к видимым карточкам. Фильтры сохраняются при сортировке.

[Официальная инструкция Shopify по фильтрам](https://help.shopify.com/en/manual/online-store/search-and-discovery/filters).

## Данные каждого товара

Название, описание, фото, цена, варианты и наличие редактируются в **Products → нужный товар**. Первое фото служит обложкой каталога; привязка фото к варианту позволяет менять его при выборе варианта. Фото показываются целиком. Галерея выводит фотографии из Media; видео и 3D-модели в этой версии галереи не выводятся.

Дополнительные поля создайте в **Settings → Custom data / Metafields and metaobjects → Products → Add definition**. Namespace/key должны совпадать с таблицей.

| Поле | Namespace/key | Тип |
|---|---|---|
| Короткое название карточки (обычное название остаётся резервным) | `custom.catalog_title` | Single line text |
| Краткое описание для карточки и первого экрана | `custom.short_description` | Single line text |
| Материал | `custom.material` | Single line text |
| Размеры | `custom.dimensions` | Single line text |
| Условия и способы гравировки | `custom.engraving_details` | Multi-line text |
| Комплектация и упаковка | `custom.packaging` | Multi-line text |
| Изготовление и доставка | `custom.production_delivery` | Multi-line text |
| Разрешить поле текста гравировки | `custom.personalization_enabled` | True or false |
| Пояснение к полю гравировки | `custom.personalization_note` | Multi-line text |
| Коллекция похожих товаров | `custom.related_collection` | Collection reference |

Заполняйте значения внизу записи конкретного товара. Пустые блоки характеристик, гравировки и упаковки скрываются. Для сроков при отсутствии данных используется редактируемый общий текст без обещания конкретной даты.

**Текст гравировки:** поле появляется только при `custom.personalization_enabled = true` и включённом **Allow engraving text field** в теме. Перед включением установите цену и объясните в `custom.personalization_note`, что входит в неё. Это поле сохраняет текст в позиции корзины и заказа; оно не рассчитывает доплату и не создаёт макет автоматически. Для разных имён на каждом изделии используйте корпоративную заявку.

Для похожих товаров используется `custom.related_collection`, затем коллекция из настроек секции, затем первая коллекция товара. Текущий товар исключается; при отсутствии других товаров блок скрыт.

## Корпоративная заявка

На странице товара **Request a Bulk Quote** ведёт к встроенной форме Shopify Contact. В отправление входят название товара, его URL, выбранный вариант, количество, контакты, компания, дата, место доставки и детали проекта. Выбор варианта и количества обновляет данные заявки. Количество в форме заявки можно задать отдельно.

Поле **Link to your logo / artwork** принимает общедоступную ссылку на файл. Прямой загрузки файла в этой форме нет. Существующая Shopify Forms на странице Request a Quote остаётся отдельной формой.

Заявки Shopify Contact отправляет на **Sender email**, настроенный в магазине. Проверьте получателя в **Settings → Notifications → Sender email** и отправьте тестовую заявку после загрузки темы. Уведомления о новых покупках настраиваются отдельно. [Shopify: назначение Sender email](https://help.shopify.com/en/manual/intro-to-shopify/initial-setup/setup-your-email).

## Добавить или убрать товар

- **Добавить:** Products → Add product → заполнить данные → статус Active → публикация Online Store → Save.
- **Изменить:** открыть товар в Products, изменить нужные данные и сохранить.
- **Скрыть:** снять публикацию Online Store или перевести в Draft. Запись остаётся в админке.
- **Удалить полностью:** открыть нужный товар → Delete product; перед удалением проверьте выбранную запись.

## Что проверить в Preview

1. Каталог `/collections/all` и категорию, фильтры, сортировку, переход на следующую страницу.
2. Товар с несколькими фото и вариантами: цена, наличие, фото и переход в корзину.
3. Товар с включённой гравировкой: текст должен отображаться в корзине и тестовом заказе.
4. Корпоративную заявку: выбранный вариант и количество должны попасть в письмо.
5. Корзину: изменение количества, удаление позиции, переход к Checkout.
6. Повторить каталог и товар на телефоне. Публиковать после проверки магазина.

Локальные проверки проверяют шаблоны и взаимодействия с тестовыми данными. Приём оплаты и доставка писем проверяются в Shopify.
