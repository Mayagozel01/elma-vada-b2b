## Цены

Причина отсутствия цен — выключенная настройка **Theme settings → Product catalog → Show agreed product prices on cards**. Это намеренное предыдущее решение, не ошибка CSS или отсутствие Shopify Price. Настройка сохранена; цена при включении берётся из `product.price_min` и форматируется `money`. Разные цены вариантов получают префикс From; единая цена — без него. Розничная цена не называется оптовой; корпоративная сумма уточняется через Request a Bulk Quote.

В редакторе проверяемой темы включите этот переключатель после проверки реальных цен вариантов и Markets. Он действует на каталог, похожие товары и подборку на главной. В редакторе темы при выключенных ценах есть пояснение; покупатели его не видят.

## Статусы

Статус отображается и при скрытой цене. Источники: доступность Shopify и поля запаса конкретного варианта. Теги и названия товаров в расчёте не участвуют. Общая логика находится в `snippets/inventory-status.liquid` и используется также для выбранного варианта на странице товара.

| Сценарий | Карточка / выбранный вариант |
|---|---|
| Единственный отслеживаемый доступный вариант, положительный остаток выше порога | In stock |
| Единственный отслеживаемый доступный вариант, положительный остаток не выше порога | Low stock |
| Товар/вариант нельзя заказать | Out of stock |
| Shopify разрешает заказать, но положительный физический остаток не подтверждён (например, продолжение продаж при 0 или отключённый учёт) | Available to order |
| Только часть вариантов доступна к заказу | Some options available |
| Все варианты доступны и у каждого подтверждён положительный отслеживаемый остаток | In stock, без суммы количеств |
| Все варианты доступны, но запас части вариантов неизвестен/неположительный | Available to order, без суммы количеств |

При отключённом учёте `inventory_quantity` не является достоверным остатком и не используется для количества или Low stock. Это ограничение [документировано Shopify](https://shopify.dev/docs/api/liquid/objects/variant#variant-inventory_quantity).

Для вариантов товара не делается вид, что доступны все комплектации, если доступна лишь часть. Если Liquid вернул неполный список вариантов, карточка консервативно сообщает Some options available, а не утверждает доступность всех.

## Точное количество и порог

**Theme settings → Product catalog**:

- **Show inventory quantity** — по умолчанию выключено. При включении текст вида `In stock · 12 available` появляется только для доступного, отслеживаемого варианта с положительным известным остатком.
- В карточке количество допустимо только для товара с одним вариантом; варианты и комплектации не складываются. На странице товара число относится только к выбранному варианту и обновляется при переключении.
- При 0 / отрицательном / неизвестном остатке или отключённом учёте число не выводится. Разрешённая продажа при нуле остаётся Available to order, не In stock.
- **Low stock threshold** — по умолчанию 5, диапазон 0–20. Значение 0 отключает Low stock. Этот статус применяется только к однозначному или выбранному варианту, а не к сумме всех вариантов.

Статусы не редактируются вручную в карточках: исправляйте только достоверные данные варианта в **Products → товар → Variants → Inventory**. Решение о Continue selling when out of stock принимает владелец магазина; не включайте его только ради зелёного статуса. Реальные остатки для тестирования не менялись.

Количество, скрытое настройкой, не добавляется в атрибуты HTML этой реализацией. Это не обещание закрыть доступ ко всем публичным данным Shopify.

## Фильтр Availability и отсутствующие товары

Фильтры остаются штатными фильтрами Shopify: они отражают возможность заказа, включая продолжение продаж без положительного запаса. Это не отдельный фильтр физического склада. Карточки Out of stock всё равно открываются; на странице товара остаётся корпоративная заявка, покупка недоступного варианта отключена.

## Короткие названия

Поддержка `custom.catalog_title` уже есть и сохранена. Проверьте определение **Products → Catalog title → Single line text** в **Settings → Metafields and metaobjects / Custom data**, затем заполните поле у товара. При пустом значении отображается исходное название; автоматического обрезания по тире/запятой нет. Основные названия, SEO и URL не менялись.

Предложения для 22 существующих позиций: [catalog-short-titles.md](catalog-short-titles.md). Это рекомендации для утверждения и ручного заполнения, не уже внесённые значения. Чтобы незаполненный длинный fallback не растягивал весь ряд, текст ссылки визуально ограничен тремя строками CSS; полное название остаётся в DOM, доступном имени ссылки, подсказке title и на странице товара. Строки данных не разрезаются по тире или запятой. Фиксированная большая высота не задаётся; ссылки выравниваются по нижнему краю ряда.

## Исправить название категории в реальных данных

Название пока **не исправлено автоматически**: Shopify CLI авторизован для темы, но `shopify store execute --no-input` сообщил об отсутствии отдельной app-авторизации для Admin API. Текст не подменяется в JavaScript или Liquid.

1. **Products → Collections → Engraved Desk Accesories → Title**: задайте **Engraved Desk Accessories**, без точки, сохраните. Поле URL/handle не меняйте: `/collections/engraved-desk-accesories` остаётся прежним.
2. **Content → Menus → Catalog categories → Engraved Desk Accesories. → Name**: задайте **Engraved Desk Accessories**, сохраните меню. Ссылку оставьте на ту же коллекцию.

Заголовок коллекции и подпись меню — разные источники, поэтому нужно исправить оба. Эти правки отразятся и в текущей живой теме, поскольку данные коллекции и меню общие для тем.

Для автоматического исправления потребовалась бы отдельная авторизация Admin API с доступом к товарам/коллекциям и навигации; новая app-авторизация без участия владельца не создавалась. Не присылайте токены и пароли в чат.

## Что остаётся заполнить/проверить

- Утвердить реальные цены и включить их показ в проверяемой теме.
- Утвердить и заполнить `custom.catalog_title`; определения и значения не изменялись через API.
- Исправить оба названия категории в Admin по шагам выше.
- Подтвердить достоверность учёта остатков и выбранную политику продаж; настройка точного количества остаётся выключенной.
- Сверить полноту ассортимента и фотографии упаковки с командой. Подтверждённых отсутствующих SKU по доступным данным нет; фиктивные позиции не добавлены.
- Отправки заявок, платежи и реальные заказы проверить отдельно. Предпросмотр не публикуется автоматически.
