# Карта медиа по страницам

Эта папка — отдельные инструкции для загрузки изображений в Shopify. Она создана после просмотра доступных материалов из шести переданных папок Google Drive: Website, SMM Content, Engraving process, Elma Vada, Alda и Niko, включая доступные подпапки.

В каталоге найдено 306 файлов-фотографий и 590 видео. Фото просмотрены как миниатюры; для роликов подбор построен по обложке/кадру, поэтому перед публикацией обязательно просмотрите выбранный ролик целиком, проверьте звук, разрешение и права на публикацию.

## Как пользоваться

Актуальная сверка выполнена по экспорту **24SEP2026-0517pm**: 21 страница, 132 секции и 307 вложенных блоков. В каждом файле есть **Полный чек-лист** со всеми секциями в порядке Shopify, скрытыми блоками, текущими значениями полей, FAQ, формами, хедером и футером. Прежние таблицы в начале файла служат подбором медиа, а не полным списком блоков.

В обновлённой теме Hero внутренних страниц, B2B feature, Photo / content card, Solution card и боковое медиа формы поддерживают **Media type → Image / Video**. Видео: выберите Video, загрузите ролик и Video cover, включите Include image or video, если такой переключатель есть. Play/Pause — в центре, запуск вручную, звук выключен. Для видео поле Photo description описывает сюжет; для картинки — её alt.

1. Откройте файл нужной страницы.
2. Нажмите название файла Drive, скачайте **оригинал**, затем загрузите его через Shopify Files или прямо через выбор изображения.
3. Вставьте предложенный `Alt text` в поле **Photo description (alt)**. Alt не надо добавлять к карточке, у которой нет картинки.
4. Если отмечено **Новый кадр / макет**, это не задача срочно генерировать фальшивую фотографию. Для производства, команды, образца и кейса снимите реальный предмет. Макет согласования может быть цифровым, но должен иметь видимую подпись `Illustrative approval layout`.

## Общие правила

- Перед публикацией подтвердите разрешение на имена, логотипы, личные послания и лица на фото. Не называйте изображение кейсом известной компании, если нет разрешения.
- Alt описывает только видимое. Он не должен включать Dallas, цену, `best`, сроки или SEO-ключевые слова, если их нет на кадре.
- Карточки процесса, FAQ и формы не обязаны иметь фото. Лучше оставить слот без фотографии, чем ставить неподходящий товар.
- Видеоролик должен стартовать только после Play и без звука. Используйте реальный кадр ролика как poster, а не декоративную картинку.
- Для главной и внутренних hero выбирайте горизонтальный кадр; для карточек — 4:3. Не обрезайте ручку, имя или гравировку в мобильной версии.
