# Elma Vada — Shopify theme

**Start here / Начните здесь: [START-HERE-RU.md](START-HERE-RU.md).**

Это единственная актуальная инструкция: загрузка темы, логотипы, баннер, контент, страницы и проверка запуска. Выполняйте по одному шагу; уже сделанное повторять не нужно.

Старые инструкции и отчёты перенесены в `docs/archive-instructions/` только для истории. Код темы и ZIP при этой уборке не изменены. GitHub не публикует тему в Shopify автоматически.
