Как заполнить: **Settings → Metafields and metaobjects / Custom data → Products** → проверьте определение `custom.catalog_title` типа **Single line text**. Затем **Products → нужный товар → Metafields → Catalog title**, введите утверждённое значение и сохраните. Для нескольких позиций можно использовать Bulk edit с колонкой соответствующего metafield. Пустое поле оставляет исходное название.

Названия разных позиций намеренно не объединены автоматически: похожие ручки и наборы остаются отдельными товарами. Условия коллекций по Product type/тегам не меняйте ради заголовка карточки.
