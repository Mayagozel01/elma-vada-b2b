# Elma Vada — Shopify theme

**Start here / Начните здесь: [START-HERE-RU.md](START-HERE-RU.md).**

Это единственная актуальная инструкция: загрузка темы, логотипы, баннер, контент, страницы и проверка запуска. Выполняйте по одному шагу; уже сделанное повторять не нужно.

Старые инструкции и отчёты перенесены в `docs/archive-instructions/` только для истории. Код темы и ZIP при этой уборке не изменены. GitHub не публикует тему в Shopify автоматически.

Локальная доработка офферов (17 ноября 2026): только корзина, постоянные карточки и окно через 5 секунд. [модель данных, настройка Shopify и чек-лист](docs/gift-offers-and-volume-pricing.md). Enable cart gift offers по умолчанию выключен; Shopify и существующая форма не изменялись.

Архив от 16 ноября 2026 (без доработки от 17 ноября) объединяет свежие картинки/тексты из Shopify с локальными офферами: [архив и отчёт сверки](docs/shopify-merge-2026-11-16.md).
